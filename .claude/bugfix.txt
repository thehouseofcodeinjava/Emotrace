## ISSUE 3: Dynamic Greeting Based on Time of Day

**Problem:**
- Current: Always shows "Good morning, Piyush"
- User needs: Change based on actual time (morning/afternoon/evening)

**Current Behavior:**
```
Good morning, Piyush ← Even at 8 PM!
```

**Expected Behavior:**
```
6:00 AM - 11:59 AM  → "Good morning, Piyush"
12:00 PM - 5:59 PM  → "Good afternoon, Piyush"
6:00 PM - 11:59 PM  → "Good evening, Piyush"
12:00 AM - 5:59 AM  → "Good night, Piyush"
```

**Fix Implementation:**

```dart
String getGreeting() {
  final hour = DateTime.now().hour;
  
  if (hour >= 6 && hour < 12) {
    return "Good morning";
  } else if (hour >= 12 && hour < 18) {
    return "Good afternoon";
  } else if (hour >= 18 && hour < 24) {
    return "Good evening";
  } else {
    return "Good night";
  }
}

// Usage:
Text(
  '${getGreeting()}, Piyush',
  style: TextStyle(
    fontSize: 20,
    fontWeight: FontWeight.bold,
    color: Colors.white,
  ),
)
```

**Status:** [ ] Ready to fix

## ISSUE 4: Fix Day Counter Logic (CRITICAL)

**Problem:**
- Current: Log 5-6 moods on April 16 → Shows "2 days"
- User needs: Should show "1 day" (April 16)
- Root cause: Moods not properly grouped by date

**Current Behavior:**
```
Input: 
  Mood 1: April 16, 09:00, score 5
  Mood 2: April 16, 14:00, score 5
  Mood 3: April 16, 18:00, score 6
  Mood 4: April 16, 20:00, score 7
  Mood 5: April 16, 22:00, score 8

Output: "Day 1, Day 2" ← WRONG (says 2 days)
```

**Expected Behavior:**
```
Output: "Day 1 (April 16)" ← All 5 moods grouped under 1 day
```

**Root Cause Analysis:**
The `groupMoodsByDay()` function is not properly extracting only the date part (year, month, day) and ignoring the time component.

**Fix Implementation:**

1. Update `MoodEntry` model to ensure clean date extraction:
```dart
class MoodEntry {
  final String id;
  final DateTime timestamp;
  
  // Extract date without time component
  DateTime get dateOnly {
    return DateTime(timestamp.year, timestamp.month, timestamp.day);
  }
}
```

2. Fix `groupMoodsByDay()` in `mood_service.dart`:
```dart
Map<DateTime, List<MoodEntry>> groupMoodsByDay(List<MoodEntry> moods) {
  final grouped = <DateTime, List<MoodEntry>>{};
  
  for (final mood in moods) {
    // Use dateOnly to remove time component
    final dateKey = mood.dateOnly;
    
    if (!grouped.containsKey(dateKey)) {
      grouped[dateKey] = [];
    }
    grouped[dateKey]!.add(mood);
  }
  
  // Sort by date (newest first)
  final sorted = Map<DateTime, List<MoodEntry>>.fromEntries(
    grouped.entries.toList()..sort((a, b) => b.key.compareTo(a.key))
  );
  
  return sorted;
}
```

3. Update home screen to display correctly:
```dart
// Get today's date only

  DateTime.now().month,
  DateTime.now().day,
);
```

4. Verify in database storage:

- When querying, group by `DateTime(year, month, day)` only

**Testing:**

## ISSUE 7: Calendar Heatmap Color Scheme & Real-time Update

**Problem:**
- Current: Colors not distinctive (4-6 and 7-10 both yellow)
- Expected: Clear visual distinction based on mood score
- Also: Colors not updating in real-time when new mood logged

**Current (WRONG) Color Scheme:**
```
4-6:   #FFD700 (Yellow)
7-10:  #F5B04C (Dark yellow) ← Can't differentiate!
```

**Expected Color Scheme (DISTINCTIVE):**
```
Score 1-2:   #5D2E2E (Very dark red - Critical low)
Score 3-4:   #8B4545 (Dark crimson - Low mood)
Score 5-6:   #D4AF37 (Gold - Neutral/Moderate)
Score 7-8:   #FFD700 (Bright gold - Good)
Score 9-10:  #FFF8DC (Very bright cream/gold - Excellent)
```

**Fix Implementation:**

1. Create distinctive color mapping:
```dart
Color getHeatmapColor(double averageMoodScore) {
  if (averageMoodScore >= 9.0) {
    return Color(0xFFFFF8DC); // Cream/Very bright gold
  } else if (averageMoodScore >= 7.0) {
    return Color(0xFFFFD700); // Bright gold
  } else if (averageMoodScore >= 5.0) {
    return Color(0xFFD4AF37); // Gold (neutral)
  } else if (averageMoodScore >= 3.0) {
    return Color(0xFF8B4545); // Dark crimson
  } else {
    return Color(0xFF5D2E2E); // Very dark red
  }
}
```

2. Update calendar grid to recalculate on mood change:
```dart
Consumer(
  builder: (context, ref, child) {
    // WATCH mood entries - rebuilds when new mood added
    final allMoods = ref.watch(moodEntriesProvider);
    
    return GridView.builder(
      gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(crossAxisCount: 7),
      itemCount: daysInMonth,
      itemBuilder: (context, index) {
        final day = index + 1;
        final date = DateTime(year, month, day);
        
        // Calculate average for this day
        final dayMoods = allMoods.where((m) => m.dateOnly == date).toList();
        final average = dayMoods.isEmpty 
          ? 0.0 
          : dayMoods.fold<int>(0, (sum, m) => sum + m.moodScore) / dayMoods.length;
        
        // Get color based on average
        final cellColor = getHeatmapColor(average);
        
        return Container(
          decoration: BoxDecoration(
            color: cellColor,
            border: Border.all(color: Color(0xFF444444), width: 0.5),
            borderRadius: BorderRadius.circular(4),
          ),
          child: Center(
            child: Text(
              day.toString(),
              style: TextStyle(
                color: average > 5 ? Colors.black : Colors.white,
                fontSize: 12,
                fontWeight: FontWeight.bold,
              ),
            ),
          ),
        );
      },
    );
  },
)
```

3. Ensure Riverpod provider watches mood entries:
